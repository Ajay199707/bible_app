================================================================================
IMPLEMENTATION GUIDE: QURAN & BHAGAVAD GITA APPS
(Based on the English/Tamil Holy Bible App Architecture)
================================================================================

This document outlines how to reuse 90% of your current Bible App code to build 
fully-featured Quran and Bhagavad Gita applications with parallel English/Tamil views, 
audio narration support, search, bookmarks, and PWA capabilities.

--------------------------------------------------------------------------------
1. DATA STRUCTURE MAPPING (JSON FILES)
--------------------------------------------------------------------------------

A. QURAN DATA STRUCTURE (data/quran_english.json / data/quran_tamil.json)
In the Bible app, database is: Book -> Chapter -> Verse.
In the Quran, it maps directly as:
- Book: Always 1 (The Quran)
- Chapter: Surah (1 to 114)
- Verse: Ayah (varies per Surah)

Example JSON layout matching the Bible reader engine:
{
  "Book": [
    {
      "Chapter": [
        {
          "Verse": [
            { "Verse": "In the name of Allah, the Entirely Merciful..." },
            { "Verse": "[All] praise is [due] to Allah..." }
          ]
        }
      ]
    }
  ]
}

B. GITA DATA STRUCTURE (data/gita_english.json / data/gita_tamil.json)
In the Bhagavad Gita, it maps as:
- Book: Always 1 (Srimad Bhagavad Gita)
- Chapter: Adhyaya (1 to 18)
- Verse: Shloka (varies per chapter, 700 total verses)

Example JSON layout matching the Bible reader engine:
{
  "Book": [
    {
      "Chapter": [
        {
          "Verse": [
            { "Verse": "Dhritarashtra said: O Sanjaya, assembled on the holy land..." }
          ]
        }
      ]
    }
  ]
}

--------------------------------------------------------------------------------
2. REUSING THE FRONTEND ARCHITECTURE
--------------------------------------------------------------------------------

You can copy the folders directly and edit these key areas:

A. LIST OF BOOKS (src/data/books.js)
- For the Quran, define a single "book" in the array representing all 114 Surahs:
  export const QURAN_SURAHS = [
    { id: 1, nameEn: "Al-Fatihah", nameTa: "அல்-ஃபாத்திஹா", chapters: 7 }, // chapters represents total Ayahs in this Surah
    ...
  ];
- For the Gita, define a single "book" in the array representing all 18 Chapters:
  export const GITA_CHAPTERS = [
    { id: 1, nameEn: "Arjuna Visada Yoga", nameTa: "அர்ஜுன விஷாத யோகம்", chapters: 47 }, // chapters represents total Shlokas
    ...
  ];

B. CORE READER ENGINE (src/modules/reader.js)
- Keeps the same rendering layout: dual parallel, only English, or only Tamil.
- The CSS styles (obsidian gold theme, cards, font sizes) will work out of the box.

C. SYSTEM & TTS AUDIO NARRATOR (src/modules/audio.js)
- Waking up the audio context on user gesture (with silent speak) is already fully working.
- Keep the Web Speech API (native browser TTS) as primary with ResponsiveVoice as secondary.
- Change the fallback languages if needed:
  - English: `en-US`
  - Tamil: `ta-IN`
  - Hindi (for Sanskrit shloka translations): `hi-IN`

D. STATIC PRELOADER (index.html & main.js)
- The 2.5-second preloader guarantees database files and voice arrays load properly.
- Update the spinning logo in the center of the preloader:
  - For Quran: Crescent moon/star icon or calligraphic logo.
  - For Bhagavad Gita: Dharma wheel icon or peacock feather.

--------------------------------------------------------------------------------
3. FREE & OPEN DATASETS
--------------------------------------------------------------------------------

A. QURAN SOURCES:
- Fawaz Ahmed's Quran API: https://github.com/fawazahmed0/quran-api
  - Offers full Surah JSONs in English and Tamil.
  - CDN links for direct fetching:
    - English: https://cdn.jsdelivr.net/gh/fawazahmed0/quran-api@1/editions/eng-abdulhaleem.json
    - Tamil: https://cdn.jsdelivr.net/gh/fawazahmed0/quran-api@1/editions/tam-abdulhameedbaqa.json

B. GITA SOURCES:
- Gita API Repository: https://github.com/gita/bhagavad-gita-api
- Bhagavad Gita JSON data: https://github.com/praneshp1org/Bhagavad-Gita-JSON-data
- Bhagwat Gita CSV/JSON: https://github.com/i8o8i-Developer/Bhagwat-Gita-DataSet

--------------------------------------------------------------------------------
4. BUILD AND DEPLOYMENT
--------------------------------------------------------------------------------
1. Initialize local Vite configuration with base path setting `./` (to support GitHub subfolders).
2. Write sitemap.xml and robots.txt into your `public/` directory for SEO visibility.
3. Build using `npm run build` and push the built repository to GitHub.
